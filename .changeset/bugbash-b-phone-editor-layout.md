The page editor fills the screen as Figma draws it. On a phone the page name is readable on two lines, the preview stays docked under the header while you type, the line you are typing stays above the toolbar with the keyboard up, and the editor toolbar replaces the tab bar. In landscape the toolbar no longer covers the rail. At every width the section's card header and breadcrumb no longer sit above the editor, whose own header has the way back to Pages.
