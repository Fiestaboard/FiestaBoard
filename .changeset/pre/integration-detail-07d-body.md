An integration's settings now follow the Integrations design: the sample board carries a "Sample page using this integration" caption, settings groups sit under mono section labels (Account, Settings, a manifest's own sections) with switches at the end of their rows, the variables a plugin unlocks show as chips, and an outline "Use in a page…" button offers a new page or the plugin's demo page in place of the old Demo Page box.
