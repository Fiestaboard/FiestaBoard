# White Noise Plugin Documentation

This directory contains documentation and visual assets for the White Noise plugin.

## Contents

- **SETUP.md** - User-facing setup guide with configuration instructions
- **SCREENSHOTS_NEEDED.md** - Guide for capturing required screenshots (to be removed once screenshots are added)
- **white-noise-*.png** - Screenshot files showing the plugin in various configurations (to be added)

## Screenshot Requirements

The following screenshots are needed to complete the documentation:

1. `white-noise-display.png` - Hero image for README
2. `white-noise-light.png` - Light intensity example
3. `white-noise-medium.png` - Medium intensity example  
4. `white-noise-heavy.png` - Heavy intensity example
5. `white-noise-white.png` - White color variant
6. `white-noise-blue.png` - Blue color variant
7. `white-noise-violet.png` - Violet color variant

See `SCREENSHOTS_NEEDED.md` for detailed instructions on capturing these screenshots.

## Adding Screenshots

To add screenshots:

1. Capture images according to specifications in `SCREENSHOTS_NEEDED.md`
2. Save PNG or JPEG files with exact filenames listed above
3. Verify images display correctly in `README.md` and `SETUP.md`
4. Delete `SCREENSHOTS_NEEDED.md` after all screenshots are added
