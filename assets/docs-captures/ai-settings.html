AI Providers

Configure OpenAI-compatible LLMs for the “Gen AI” page generator. BYO-LLM: FiestaBoard never bundles a key.
Your prompts and the variable list of your enabled plugins are sent directly to the provider you configure. API keys are stored on this device and never sent anywhere else.

MCP / external clients

A pre-shared token that lets Claude Desktop, Claude Code, and other MCP clients talk to this FiestaBoard. The token authenticates as a single principal — scoped to the /api/mcp endpoint only — so it can't edit pages or other settings. See MCP client setup for client-specific quirks (Desktop needs an stdio proxy; claude.ai web Connectors require public HTTPS and OAuth, so they won't reach a LAN host).
Status:Not configured

No token is configured. External MCP clients will fall back to cookie auth, which Claude Desktop / Claude Code don't support — they'll fail registration with an opaque error. Generate a token to unblock them.

Home Assistant (MQTT)

Expose FiestaBoard as a device in Home Assistant via MQTT auto-discovery. Requires a running MQTT broker (e.g. Mosquitto).
