# H7 implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans, test-first. The user authorizes independent agents and autonomous decisions.

**Goal:** Provide bounded, truthful formula execution traces and board-cell origins to web/native editors.
**Architecture:** Optional debug request on the existing preview render. Instrument the evaluator once; carry source runs through existing render/layout operations.
**Tech Stack:** Python 3.11, FastAPI/Pydantic, pytest, ruff.
**Spec:** `docs/internal/adr/2026-11-17-h7-render-debug.md`.

## Global constraints

- Work only in isolated `fb-wt/cx-hubH7*` worktrees; base/PR target v11.
- No default/H5 wire changes; no changed formula semantics or bypass of S2.
- Exact limits and coordinate conventions are in the ADR.
- Shared Docker only, maximum 3; no concurrent agents using the same container.
- Commit trailer exactly `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Check program/codex/WRAPUP before starting each step; never merge.

## Review focus

1. Equal output from different atoms must retain different source coordinates.
2. Short-circuit versus eager/loop execution must match actual evaluator calls.
3. Trace/provenance limits must not change output or bypass render deadlines.
4. Wrapped rich markup, fill and alignment must preserve cell geometry and padding.
5. Preview/concurrent requests must not leak recorder state, context or source data.
